# AGENTS.md

## Goal

Enable OpenCode agents to use OpenAI-native web search through the user's ChatGPT subscription alongside their normal local and MCP tools. Keep search access governed by OpenCode's permissions and search history usable across follow-ups and resumed sessions. Users should be able to run stock OpenCode.

## Web search

Use web search whenever facts may be outdated, uncertain, version-specific, or important.
Prefer verifying over guessing. Use current sources for docs, APIs, errors, releases, prices, dates, security issues, and recommendations.
Skip research only for simple local code edits or user-provided content.
